The original source folder and its uncommitted changes remain untouched. A baseline snapshot and original-review evidence are kept in the parent workspace's evaluation directory. The GitHub integration includes the corrected assessment, current features, implementation, tests and validation record.

Narrow windows use bottom navigation.

Retained: visual shade dragging and dual grips, Jog, fine adjustment, scenes, favorites, recents, room sorting, room color indicators/icons, theme switching, connection freshness, live events, manual setup, discovery, Swagger tools and macOS build configuration.
