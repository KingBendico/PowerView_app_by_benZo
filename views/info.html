PowerView App — help

This app controls Hunter Douglas PowerView shades and scenes through your primary gateway on your home network.

Blinds

Opens first when you launch the app. Pick a room, then adjust each shade. Rooms can be sorted by gateway order, A–Z, or recent. Shades are shown as tiles: drag the window graphic or type a percentage. Dual shades (top rail + bottom hem) use two grips; single-motor shades use one.

Scenes

Use Scenes in the bottom bar to run gateway scenes. Star favorites and use recent chips for quick access.

Connection & settings

Set the gateway IPv4 address under the gear icon. Use Test connection or Open Swagger UI in settings if you need to check the hub. A yellow bar on the main window means the app cannot reach the gateway (wrong IP, hub offline, or network issue).

Tips

  • Theme: toggle light and dark with the sun/moon button on the main window.
  • Escape leaves a room's shade view and returns to all rooms.
  • Ctrl+B / Ctrl+S jump to Blinds or Scenes.
  • Ctrl+1–Ctrl+9 open the first nine rooms in the same order as the Blinds grid (Gateway / A–Z / Recent) on Windows, Linux, and Mac — use the Control key. Numpad 1–9 works too. Number badges on tiles show the shortcut.
  • If you opened this page in its own window, Escape or Close closes it. In the main app, help appears as an overlay on the same window.

Finding the gateway IP

On your router's device list, look for PowerView-G3 (or similar). If you have more than one gateway, use discovery and the gateway identity check to select the primary; IP address order is not reliable. Your hub may also answer at powerview-g3.local on some networks.
